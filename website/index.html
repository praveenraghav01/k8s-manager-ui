Bring your own LLM

An AI assistant that actually reads your cluster

Pick your model in the top toolbar and ask in plain English — “why is this pod not ready?” or “any warning events in kube-system?”. It runs an agentic tool-use loop over read-only cluster data and streams the answer back token by token.

k8sight · AI — Claude Code docked beside the cluster
  • Read-only by design — it can never modify your cluster; it shows you the kubectl command when a change is needed.
  • Grounded in live data — calls tools like logs, events and describe to base every answer on your real cluster.
  • Secrets redacted — secret values are stripped from tool output before anything reaches the API.
  • Provider-agnostic — connects to any OpenAI-compatible endpoint (TrueFoundry, OpenAI, Azure, LiteLLM…) and stays aware of your current view.
Needs your own LLM subscription. The assistant ships with no built-in model — you connect an OpenAI-compatible API (TrueFoundry, OpenAI, Azure OpenAI, LiteLLM, …), which usually requires a paid account and API key. Your key is stored locally in ~/.config/k8s-manager/config.json. Everything else in the app works without it.

First-class Argo CD support

Running Argo CD? The app auto-detects it and adds a full Argo CD workspace — no argocd CLI and no separate login. It reads the Application CRDs straight from your cluster using your kubeconfig’s own RBAC.

Native installers for every desktop. Pick your platform — each build serves the same UI on top of your kubeconfig.

macOS

Apple Silicon · .dmg

A native k8sight.app that starts the server and opens the UI in its own window, with your shell PATH repaired automatically.

Download .dmg
  1. Open the .dmg and drag k8sight to Applications.
  2. First launch: right-click → Open (ad-hoc signed).
  3. Requires kubectl installed locally.

Windows

x64 · NSIS installer (.exe)

A standard per-user installer with a Start-menu shortcut. Bundles Node so only kubectl needs to be on your PATH.

Download .exe
  1. Run the installer and follow the prompts.
  2. SmartScreen: More info → Run anyway (unsigned).
  3. Requires kubectl on your PATH.

Linux

x64 · AppImage & .deb

A portable .AppImage that runs anywhere, or a .deb for Debian & Ubuntu with a desktop entry.

Download for Linux
  1. chmod +x the AppImage, or dpkg -i the .deb.
  2. Launch k8sight from your app menu.
  3. Requires kubectl on your PATH.
