Bring your own LLM

An AI assistant that actually reads your cluster

Click the ✨ button and ask in plain English — “why is this pod not ready?” or “any warning events in kube-system?”. It runs an agentic tool-use loop over read-only cluster data and streams the answer back token by token.

AI Assistant — connect your LLM API
  • Read-only by design — it can never modify your cluster; it shows you the kubectl command when a change is needed.
  • Grounded in live data — calls tools like logs, events and describe to base every answer on your real cluster.
  • Secrets redacted — secret values are stripped from tool output before anything reaches the API.
  • Provider-agnostic — connects to any OpenAI-compatible endpoint (TrueFoundry, OpenAI, Azure, LiteLLM…) and stays aware of your current view.
Needs your own LLM subscription. Connect an OpenAI-compatible API (TrueFoundry, OpenAI, Azure OpenAI, LiteLLM). Your key is stored locally.

Why is the checkout pod stuck in Pending?
get_events describe_resource list_nodes
The checkout-7d9f pod is Pending because no node can satisfy its request of 2 CPU — all nodes are at capacity. Either scale the deployment down, add a node, or lower the CPU request. To inspect: kubectl describe pod checkout-7d9f.
Get started in a minute

Download & run

Grab the native macOS app, or spin it up anywhere with the official Docker image. Both serve the same UI on top of your kubeconfig.

macOS App

Apple Silicon (arm64) · .dmg · v1.3.0

A native Kubernetes Manager.app that starts the server and opens the UI in its own window. It reconstructs your shell PATH so kubectl is found automatically.

Download for macOS
  1. Open the .dmg and drag the app to Applications.
  2. First launch: right-click the app → Open (ad-hoc signed build).
  3. Requires kubectl installed locally.

Docker

Multi-arch (amd64 / arm64) · serves on :3001

The image bundles Node and kubectl. Mount your kubeconfig read-only and open the mapped port.

Terminal
# pull & run — UI on http://localhost:8080
docker run --rm -p 8080:3001 \
  -v "$HOME/.kube:/home/node/.kube:ro" \
  praveenraghav/k8s-manager-ui:latest
Pull only
docker pull praveenraghav/k8s-manager-ui:latest
  1. Optionally enable the AI assistant with your own OpenAI-compatible endpoint — -e LLM_BASE_URL=… -e LLM_API_KEY=… -e LLM_MODEL=… (needs a paid LLM subscription).
  2. For EKS/GKE/AKS, ensure the cloud auth CLI is available or use a static-token kubeconfig.
